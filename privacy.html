プライバシーポリシー

gmail-support ／ 制定日 2026年10月30日

gmail-support は、開発者本人が自分の Google アカウントにだけ使う個人用のアプリです。 このページでは、アプリが Google から受け取る情報の扱いを説明します。

取得する情報

  • Google アカウントのメールアドレス（どのアカウントで認証したかを区別するため）
  • Gmail のメッセージ（用途に必要な送信元からのメール）

使い方

受け取った情報は、開発者本人のコンピュータの上でだけ処理し、家計の記録と本人のメール整理にだけ使います。 メールの変更（ラベル付けなど）は、本人が指示したときにだけ行います。

保存

読み取った内容と認証トークンは、開発者本人のコンピュータと本人のバックアップにだけ保存します。 外部のサーバには送りません。

第三者への提供

受け取った情報を第三者に提供・販売することはなく、広告にも使いません。

Google API サービスのユーザーデータに関するポリシー

このアプリが Google API から受け取った情報の使用と他のアプリへの移転は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

アクセスの取り消し

Google アカウントのサードパーティ アクセスから、いつでもこのアプリのアクセスを取り消せます。

gmail-support のトップへ

Summary: gmail-support is used only by its developer for their own Google account. Data received from Google (the account's email address and Gmail messages from relevant senders) is processed and stored only on the developer's own computer and backups, is never shared, sold or used for advertising, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
